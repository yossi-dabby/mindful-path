## מגבלות שנותרו ומידע חשוב להפצה

1. **כניסה ואיפוס סיסמה בפרסום החי:** `/login` ו־`/reset-password` מחזיר מסך שמטען הסקריפטים שלו כולל `/api/frontend-config.js?v=3` ו־`/static/index-DmiZE53r.js`, במקום bundle האפליקציה תחת `/assets/`. אלה מסכים שמסופקים על ידי הפלטפורמה. `/register` ו־`/forgot-password` טוענים את bundle האפליקציה, ולכן תיקוני AuthLayout כן חלים עליהם. יישום ResetPassword במאגר כבר משתמש ב־AuthLayout, אולם אי אפשר לאשר שתיקון CSS במאגר ישנה את המסך שמגיש השרת בכתובת השמורה. נדרש בירור הגדרת ניתוב/מיתוג בפלטפורמה לפני אישור אחידות המסכים החיים האלה. חוזה API ההגדרות המתועד שנבדק אינו כולל שדות עיצוב למסכים השמורים, ולכן לא נשלחו שדות לא מתועדים ולא שונה מנגנון ההזדהות. לא שונו מנגנוני הזדהות לצורך תיקון חזותי.
2. **קבצים טיפוליים:** תכולת הספרייה הושבתה במפורש. אי אפשר לבדוק חזותית קבצים שאינם מותקנים. מצב ההשבתה נבדק ונשמר.
3. **חשבון חי:** שער הגיל, תוכן המחייב יצירה, מנוי, רשימות ריקות ומצבים שאין בחשבון הנוכחי הושלמו בבדיקות מקומיות ככל שהוגדרו fixtures; אין כאן טענה שנוצרו תוצאות טיפוליות או פוסטים בחשבון החי.
4. **מכשירים:** רוחבי מובייל וטאבלט נבדקו בדפדפן מקומי. לא בוצעה בדיקה של AAB מותקן, WebView פיזי, מקלדת מכשיר, iOS, TalkBack או Play Console בסבב זה.
5. **כיתוב ושפות:** בכמה רכיבי משנה של מטרות (התאמות AI, תזכורות, לוח משימות וקישורי יומן) קיימות מחרוזות באנגלית גם במצב עברי. המעטפות ופעולות הבסיס נבדקו; תיקון הפלטה אינו השלמת תרגום של כל המחרוזות הקיימות. תוכן משפטי לא תורגם מחדש בסבב חזותי זה.
6. **היקף:** צולמו כל המסלולים הרשומים וכניסות המשחקים. בדיקות אינטראקציה אינן ממצות כל צירוף תשובות, כל מצב מתוזמן או כל היסטוריית נתונים אפשרית. מצבי נושא ושפה שאינם במטריצה דורשים בדיקת קבלה נפרדת; תצוגות בחירת הנושא עצמן נשמרו.
7. **הפצה:** השינויים מיועדים לבקשת מיזוג נפרדת. לא בוצעו מיזוג, פרסום חדש, שינוי גרסת Android או העלאה ל־Google Play במהלך התיקונים.

## שחזור ונתוני בדיקות

```bash
npm run build
node scripts/audit-ui.mjs
node scripts/audit-ui.mjs --states
npx playwright test tests/e2e/full-ui-regressions.spec.ts
```

`audit-ui.mjs` גוזר את רשימת המסלולים מקובצי הרישום ואת המשחקים מהקטלוג. הוא מפיק תמונות ותוצאות JSON, מדמה את ה־API, חוסם כתיבות ורשת חיצונית ואינו משתמש בעוגיות או בסשן החי. `--states` מוסיף נתונים סינתטיים ואינטראקציות; כשל בסקריפט אינו נספר כאישור של אותו מצב.

בדיקות הרגרסיה מכסות את חיתוך טופס הבריאות, גלילת האשף, קישור תרגיל ללא מזהה, רשימת השמעה חסרה, כפתורי המסע, כרטיסי פרימיום בטאבלט ומצב PDF ללא קובץ. בדיקות הפרויקט הקיימות משלימות תצוגות רספונסיביות, RTL, נגישות, טפסים וזרימות שמירה באמצעות API מדומה. תוצאות הבדיקות הסופיות וקישורי CI מצורפים לבקשת המיזוג.
